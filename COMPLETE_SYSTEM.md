- **Default role**: Admin (full access)

### 2. First Steps
1. **Configure Settings** (Admin → Settings)
   - Set branch information
   - Configure email (optional)
   - Set printer preferences
   - Manage payment methods

2. **Add Staff** (Admin → Staff)
   - Create cashier accounts
   - Set permissions
   - Assign PINs

3. **Start Selling** (POS)
   - Select items
   - Choose order type
   - Process payment
   - Print receipt

### 3. Customer Display
- Click "Display" button in POS
- Choose Grid or Slideshow view
- Customers can order directly
- Cart syncs with POS

## 💡 Key Features Explained

### Auto-Print Receipts
1. Go to **Admin → Settings → Printer Settings**
2. Enable "Auto-Print Customer Receipt"
3. Set delay (default: 1.5 seconds)
4. Receipts print automatically after order

### Customer Display Mode
1. Click **"Display"** button in POS
2. Choose **Grid** or **Slideshow** view
3. Customers see large images
4. They can add items to cart directly
5. Cart syncs with POS system

### Menu Management
1. Go to **Admin → Menu**
2. Click **"Add Item"** to create custom items
3. Click **camera icon** to upload images
4. Toggle availability with eye icon
5. Remove items with trash icon

### Staff Permissions
1. Go to **Admin → Staff**
2. Click **edit** on staff member
3. Set role (Admin/Manager/Cashier/Kitchen)
4. Toggle permissions
5. Set allowed categories (optional)

### Offline Mode
- System works 100% offline
- All data saved in browser
- Email queue stores pending emails
- Auto-syncs when internet returns
- Online/offline indicator in header
